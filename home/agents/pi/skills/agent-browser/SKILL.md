---
name: agent-browser
description: Interact with websites, inspect rendered pages, fill forms, take screenshots, or test browser interfaces using the agent-browser CLI.
---

Read `agent-browser skills get core` before browser work. Use
`agent-browser skills get core --full` for command references and templates.
These instructions match the installed CLI version.

Use a named session for each task, following the CLI's session guidance. Close it
when finished. Take a new snapshot after navigation or page changes before using
element references.

For Electron apps or exploratory testing, find the relevant guide with
`agent-browser skills list` and load it with `agent-browser skills get <name>`.
